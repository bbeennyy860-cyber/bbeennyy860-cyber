## `02 / SELECTED SYSTEMS`

### [`helios-vps-runner`](https://github.com/bbeennyy860-cyber/helios-vps-runner) · safe remote operations

A Python CLI that runs scripts on allowlisted servers through content scanning, a two-stage apply gate and structured execution receipts. Every remote run produces an append-only forensic record. The repository includes 28 network-isolated tests.

### [`Arbiter`](https://github.com/bbeennyy860-cyber/arbiter) · governed agent payments

A payment agent where deterministic policy runs before model judgement and one governed `settle()` path controls execution. Co-built with Alex Kurkar for the Nous Research × NVIDIA × Stripe hackathon. I owned the backend policy engine, agent core, ledger, operator loop and test suite. Stripe remains in test mode.

### `SportsQuantX` · commissioned event-market engineering

A private commissioned backend for an event-market trading product. My work covers asynchronous orchestration, order execution, reconciliation, risk controls and operator tooling on Linux infrastructure. Source and client details remain confidential.

### [`moodle-sync`](https://github.com/bbeennyy860-cyber/moodle-sync) · university automation

A personal tool that mirrors enrolled Moodle modules through the REST API, downloads new course material and tracks deadlines. Incremental sync state keeps nightly runs small and repeatable.
